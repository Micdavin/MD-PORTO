# Michael Davin - Portfolio

Static portfolio with 28 project showcases, interactive 3D, responsive layouts, and image-based project previews.

## Deploy to Vercel

Import this repository. Keep Root Directory at the repository root, choose Framework Preset **Other**, leave Build Command and Install Command empty, and use **public** as Output Directory. These settings are included in vercel.json. No environment variables, database, npm installation, or persistent Node server are required.

## Files

- public/: all website runtime files, including index.html and assets.
- vercel.json: static deployment configuration.
- .gitignore: local files excluded from Git.

## Updates

Update files in public/ and commit to the connected production branch. Vercel can deploy updates through its GitHub integration.

Third-party library license notices are retained in public/assets/vendor/. Project source attribution is displayed in the corresponding project detail when provided.

Documentation: https://vercel.com/docs/builds/configure-a-build
